# homebrew-tap

Homebrew tap for tools by [kjanat](https://github.com/kjanat).

```sh
brew install kjanat/tap/actionlint
```

| Cask | Source |
| --- | --- |
| `actionlint` | [kjanat/actionlint](https://github.com/kjanat/actionlint) |

The casks in `Casks/` are generated by [GoReleaser](https://goreleaser.com/) on every release of their source repository.
Do not edit them by hand.
